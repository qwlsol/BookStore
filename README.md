## Описание тестовых сценариев
Все тесты написаны с использованием **xUnit**. Проект тестов называется "BookStoreTests". Всего было написано 14 тестов.
### Что именно проверяется
1. Модель Book (3 теста)
- Если не заполнить название вылезет ошибка "Требуется ввести название"
- Если цена 0 или отрицательная вылезет ошибка "Цена должна быть от 1 до 1000000"
- Если всё заполнено правильно, то валидация проходит
2. Модель Buyer (3 теста)
- Если не заполнить фамилию — ошибка валидации
- Если email написан правильно (например, test@example.com) — всё хорошо
- Если email написан неправильно (например, просто "почта") — ошибка
3. Контекст базы данных (3 теста)
Проверяется, что через DbContext можно сохранить:
- книгу
- покупателя
- автора
4. Страница Index со списком книг (2 теста)
- Проверка, что модель страницы вообще создаётся
- Проверка, что при вызове OnGet книги подгружаются из БД
5. Страница Create (добавление книги) (3 теста)
- Проверка, что модель существует
- Если отправить нормальную книгу, тогда сохраняется и перебрасывает на список
- Если отправить книгу без названия, то остаётся на этой же странице (не сохраняет)
